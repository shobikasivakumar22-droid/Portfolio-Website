PUBLISH FREE WITH GITHUB PAGES
1. Sign in to https://github.com using your account.
2. Create a new public repository named shobikasivakumar22-droid.github.io
   (or another repository name if you prefer).
3. Upload index.html, style.css, script.js, and the assets folder.
4. Open the repository's Settings > Pages.
5. Under Build and deployment, select Deploy from a branch, choose main and /(root), then Save.
6. Wait for GitHub Pages to publish the site. The address will usually be
   https://shobikasivakumar22-droid.github.io/
   if the repository name matches the account username.
7. If you use a different repository name, the URL will usually include that repository name.
